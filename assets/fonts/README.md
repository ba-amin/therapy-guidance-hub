# Bundled fonts

These unmodified WOFF2 variable fonts are loaded by `styles/shared.css`. They are
stored locally to support offline reading and consistent typography without
third-party font requests. Keep this directory with the HTML and stylesheets.
Browsers download only the fonts needed for the current page and language.
